TrueType copies of the site's fonts for embedding in the PDF exports (generated from the
self-hosted WOFF2 files: Fraunces instanced at weights 500 and 700, Atkinson Hyperlegible
Next 400/700, Latin subset). Same SIL Open Font License as the originals: see
../LICENSE-Fraunces-OFL.txt and ../LICENSE-AtkinsonHyperlegibleNext-OFL.txt.
`metrics.json` holds the WinAnsi glyph widths used for layout.
